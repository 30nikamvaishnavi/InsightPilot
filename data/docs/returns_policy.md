# Returns Policy

## Return window
Customers have 30 days from the order date to return an item. Requests after 30 days are rejected unless the item arrived damaged.

## Refund amounts
Damaged products and wrong items receive a full refund of the order value. Items returned because the customer changed their mind receive a refund of 90 percent of the order value after a restocking fee.

## Return reasons
Every return is logged with one of three reasons: Damaged, Wrong item, or Changed mind. The reason is stored in the reason column of the returns table.
